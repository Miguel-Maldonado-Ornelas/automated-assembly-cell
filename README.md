# Automated Assembly Cell

Automated assembly cell developed in **Siemens TIA Portal V17** using an **S7-1200 PLC**, HMI, PROFINET communication, state-machine control, and fault diagnostics.

## Project Overview

This project demonstrates the design and programming of an automated industrial assembly cell, including sequence control, sensor and actuator management, HMI operation, and fault handling.

## Technologies

* Siemens TIA Portal V17
* Siemens S7-1200 PLC
* HMI
* PROFINET
* State-machine control
* Industrial automation
* Fault diagnostics

## Main Features

* Automated assembly sequence
* PLC-based control
* HMI operator interface
* Sensor and actuator control
* PROFINET communication
* State-machine sequence management
* Fault detection and diagnostics

## Project Status

The automated assembly sequence has been tested and validated in simulation.
